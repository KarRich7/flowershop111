# Демо-изображения

Все фотографии товаров в `products/` (b01–b20 букеты, f01–f15 цветы, g01–g04 зелень,
p01–p04 упаковка, r01–r03 ленты, a01–a03 дополнения) — **AI-сгенерированные демо-изображения**,
созданные специально для тестового MVP. Это не фотографии реальных букетов магазина:
перед запуском в продакшн их нужно заменить на собственные фото.

Открытки c01–c03 нарисованы программно (Pillow).

`brand/banner.jpg` — логотип/баннер «Цветы Урала», предоставленный заказчиком.

## Фото для конструктора (`constructor/`)

* `f01–f15.webp` (головки цветов) и `g01–g04.webp` (веточки зелени) вырезаны из тех же
  AI-сгенерированных демо-фото `products/f*.jpg` и `products/g*.jpg`: фон удалён
  нейросетью rembg (модель isnet-general-use), края подчищены вручную/скриптом.
* `p01–p04.jpg` — текстуры упаковки: p01–p02 сгенерированы программно, p03–p04 —
  фрагменты демо-фото `products/p03.jpg`, `products/p04.jpg`.

Перед запуском замените их своими фото в админке: карточка товара → «Фото для конструктора».
